# Spring Boot initial
[Spring Boot official documentation](https://docs.spring.io/spring-boot/documentation.html)

## Instal java and mvn in Linux
```bash
sudo apt update
sudo apt install openjdk-21-jdk maven -y
```
[Java for windows](https://www.java.com/es/download/manual.jsp)<br>
[Mvn for windows](https://maven.apache.org/download.cgi)

## Verify the instalation and update
```bash
java -version
mvn -version
```
### Update
```bash
sudo apt update
sudo apt install openjdk-21-jdk maven -y
```

## Create the project
[Create the project in line](https://start.spring.io/)
```bash
curl -G https://start.spring.io/starter.zip \
  --data-urlencode "type=maven-project" \
  --data-urlencode "language=java" \
  --data-urlencode "bootVersion=4.0.2" \
  --data-urlencode "baseDir=store-api" \
  --data-urlencode "groupId=com.example" \
  --data-urlencode "artifactId=store-api" \
  --data-urlencode "name=store-api" \
  --data-urlencode "packageName=com.example.store" \
  --data-urlencode "javaVersion=21" \
  --data-urlencode "dependencies=web,data-jpa,postgresql,validation" \
  -o store-api.zip
```

## Verify dependencies
```bash
./mvnw dependency:tree
````

## Launch the application
```bash
./mvnw spring-boot:run
````

## Create the folder structure
```bash
cd src/main/java/com/example/store

mkdir -p config controller service repository entity
mkdir -p dto/request dto/response
mkdir -p mapper exception
````
